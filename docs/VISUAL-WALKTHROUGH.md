# Nexora — Visual Product Walkthrough

Explore Nexora through the [**product walkthrough**](walkthrough/README.md). It follows the visitor journey from creating a private workspace through catalog management, competitor price collection, alerts, website discovery, account settings, and role-specific views.

The screenshots are refreshed from the connected browser journey against the real frontend and API, using a disposable PostgreSQL database. The price-collection example uses controlled public structured product pages so the observation-and-alert flow remains repeatable; the example prices are illustrative, not live market quotes.
